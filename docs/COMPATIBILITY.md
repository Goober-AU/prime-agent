# COMPATIBILITY

Contract decisions, deviations and remaining non-Rust needs for the optimus-rust port.
Read alongside docs/BASELINE.md (what parity means) and docs/PORT-RULES.md (how to port).

## Language boundary

| Layer | Decision |
|---|---|
| TypeScript/JavaScript application layer | Ported to Rust (this repository's `crates/`) |
| Python / IPython runtime | STAYS PYTHON. No `.py` file is translated, edited or replaced. |
| Rust -> Python transport | Newline-delimited JSON over the child's stdin/stdout, protocol version 3, started as `python -m rlm.repl` |

The Python runtime does not need to know whether its caller is TypeScript or Rust.
`prime-agent-runtime/src/rlm/repl.md` is the protocol contract; the Rust port implements
the host side of it.

## Isolation contract

Reference (TypeScript) and candidate (Rust) tests run with SEPARATE kernel processes,
namespaces, files and state, in a PRIVATE venv built from the same pinned interpreter
and package versions. Neither side connects to production Python. See
`evidence/isolation-and-python-env.md`.

Private environment map (mirrors `scripts/port-isolation.ps1`):
`PRIME_AGENT_CODING_AGENT_DIR`, `PI_CODING_AGENT_DIR`, `PRIME_AGENT_SESSION_DIR`,
`PRIME_AGENT_CODING_AGENT_SESSION_DIR`, `PRIME_AGENT_KERNEL_PYTHON`,
`PRIME_AGENT_KERNEL_VENV`, `PYTHONPATH`, `TEMP`/`TMP`, `HOME`/`USERPROFILE`.

## Known deviations and open items

Tracked here as they are confirmed. Every entry names the evidence.

1. **Dynamic JS/TS extensions.** A Rust host cannot execute arbitrary existing
   JavaScript/TypeScript extensions without a JS engine or a Node sidecar. This is the
   one architectural conflict that needs a user decision; it is NOT silently resolved.
   Status: open, reported.
2. **Generated model catalog.** `packages/ai/src/models.generated.ts` (22,884 lines) is
   data, not logic. The port keeps the same data; see the Rust module's own header for
   how it is stored and regenerated.
3. **Test correction provenance.** The reference checkout has two uncommitted test
   changes (daemon-supervisor-ownership, rlm-ledger). They are not part of the pinned
   commit and were not copied. Status: not yet reproduced here.

## Verification status

`scripts/gen-migration-map.py`) and the differential baselines in `evidence/`.
"Compiles" is not "ported"; only files whose worker report says `ported` AND whose
crate build is green are marked verified in that table.
